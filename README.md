# BadCheff

Decompiled source of the **BadCheff** Android game (Godot engine).

Generated by decompiling `badcheff.apk` with:

- [apktool](https://github.com/iBotPeaches/Apktool) — resources, manifest and `smali`
- [jadx](https://github.com/skylot/jadx) — reconstructed Java/Kotlin sources

## Layout

- `res/` — apktool output (decoded resources, `AndroidManifest.xml`, `smali`, `assets`)
- `src/` — jadx output (reconstructed sources under `src/sources`)

The actual game logic lives in the Godot project files inside `res/assets`
(`.gd`/`.gdc` scripts, scenes, etc.). `res/lib` contains the native Godot
engine libraries.
